# Mockups

## Purpose

Mockups are presentation assets used to visualize configured products. They are not the source of truth for production artwork.

## Workflow

At a conceptual level:
1. select the relevant product/variant scope;
2. determine supported placements/print files;
3. provide suitable artwork;
4. request/generate mockup output using the current supported Printful workflow;
5. retrieve completed output when the workflow is asynchronous;
6. save final assets appropriately if generated URLs are temporary.

Do not hard-code polling intervals, response fields, or URL lifetime assumptions. Verify current developer documentation when exact API behavior matters.
